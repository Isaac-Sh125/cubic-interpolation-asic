Standard-Compile vs Compile-Ultra LEC Summary
==============================================

Purpose
-------
A second logical-equivalence check was performed to verify that the current
project implementation synthesized using standard Design Compiler compile and
the current implementation synthesized using compile_ultra preserve the same
functional behavior.

The comparison is gate-level to gate-level.

Golden:
  current-project standard compile + clock gating + scan implementation

Revised:
  current-project compile_ultra + clock gating + scan implementation

Functional scan configuration
-----------------------------
The comparison evaluates normal functional operation:

  scan_en    = 0
  scan_in1   = 0
  scan_in2   = 0
  scan_in3   = 0

The scan outputs are excluded from the functional comparison.

Comparison configuration
------------------------
Cadence Conformal hierarchical LEC was used with:

  set analyze option -auto
  set compare effort high

The high-effort setting is used for this standard-vs-ultra gate-level
comparison because the two synthesis strategies can produce substantially
different internal structures while preserving the same function.

Interpretation
--------------
The standard-compile and compile_ultra implementations have different internal
synthesis structures and different modeled key-point counts. Conformal maps the
corresponding functional points before comparison.

The final hierarchical result demonstrates functional equivalence between the
two current-project synthesized implementations under the documented functional
scan constraints.
