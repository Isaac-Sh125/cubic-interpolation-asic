# Keysight VSA Conversion Utilities

This directory contains the MATLAB utilities used to convert project I/Q
results into MAT files that can be loaded into Keysight PathWave Vector Signal
Analysis (VSA).

## Floating-Point MATLAB Results

`float_iq_to_vsa.m` converts a two-column floating-point I/Q text file into a
Keysight-compatible MAT file.

Input format:

    I(float)   Q(float)

The generated MAT file contains:

- `Y` - complex I/Q sample vector
- `XDelta` - sample interval in seconds
- `InputZoom` - VSA amplitude scaling
- `XStart` - start time

The sampling frequency is supplied explicitly, allowing the same converter to
be used for every supported interpolation factor.

Example for L=5:

    float_iq_to_vsa( ...
        'cubic_fixed16_strict_output_POST_LPF_L_5.txt', ...
        300e6, ...
        'matlab_post_filter_L5.mat');

## RTL Hexadecimal Results

`hex_iq_to_vsa.m` converts the two-column hexadecimal I/Q output generated by
the RTL testbench into the same Keysight-compatible MAT representation.

Input format:

    I_hex   Q_hex

The final RTL FIR output is interpreted as:

- signed two's-complement representation
- word length: 16 bits
- fractional bits: 14

The output sampling frequency is derived from:

    fs_out = L * 60 MS/s

Therefore:

| L | Output sample rate |
|---:|---:|
| 2 | 120 MS/s |
| 3 | 180 MS/s |
| 4 | 240 MS/s |
| 5 | 300 MS/s |

Example for L=5:

    hex_iq_to_vsa( ...
        'rtl_output_POST_LPF_L_5.txt', ...
        5, ...
        'rtl_L5.mat');

## MATLAB and RTL FIR Difference

The MATLAB and RTL post-filter signal paths intentionally use different FIR
implementations.

The MATLAB algorithmic reference uses a 64-tap low-pass FIR, while the final
RTL implementation uses a 10-tap symmetric FIR with an L-dependent coefficient
bank.

Keysight VSA is therefore used to evaluate end-to-end 64-QAM signal quality.
The MATLAB and RTL post-filter outputs are not presented as bit-exact
equivalent signals.

## EVM Interpretation

Keysight VSA reports EVM continuously during signal analysis. The displayed
value can vary slightly with the active measurement interval and analyzer
state.

For this reason, the project preserves representative VSA screenshots rather
than treating a displayed EVM reading as an immutable constant.

In the preserved RTL screenshots for L=2, 3, 4, and 5, representative EVM
readings are approximately in the 176-267 m%rms range.

All captured RTL operating modes remain below the project requirement:

    EVM < 350 m%rms

The individual screenshot readings and their interpretation are documented in:

    results/verification/keysight_vsa_summary.txt

## Supported Operating Modes

The original input sample rate is 60 MS/s.

The supported interpolation factors and corresponding output sample rates are:

- L=2: 120 MS/s
- L=3: 180 MS/s
- L=4: 240 MS/s
- L=5: 300 MS/s
